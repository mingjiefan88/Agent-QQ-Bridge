Codex专用Windows QQ机器人插件，包含统一启动器、首次配置、QQ扫码、人格设置和嵌入式监控。QQ客户端和Codex账号需由使用者自行准备。

Windows完整包附带未修改的NapCat4.18.41官方压缩包及Node22.14.0便携运行时，附完整许可、来源与SHA256。含NapCat的完整包限非商业使用，不能视为整体MIT。

下载zip与对应.sha256，验证后解压，双击“启动机器人.cmd”。初次进入配置引导，日常进入状态监控。源代码版也可安装，缺失依赖会从官方固定地址下载并校验。

自动测试使用模拟QQ收发，不代表新账号真实群聊端到端验收。生图、视觉与音源访问仍取决于实际Codex账号、CLI和音源可用性。当前版本为beta，请先小范围部署。
