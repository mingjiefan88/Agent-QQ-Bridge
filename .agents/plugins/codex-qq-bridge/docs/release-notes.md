# 1.0.0 正式版说明

Codex 专用 Windows QQ 机器人，统一界面包含首次配置、Codex 连接、QQ 扫码、主人与群绑定、人格、功能开关和实时监控。没有运行时 npm 依赖，使用者自行准备官方 QQ 客户端、Codex CLI 与账号。

## 正式版内容

- 群上下文、实际 @ 与话题对象识别、按发送者隔离的记忆、图片理解、点歌、表情、戳一戳和权限核验后的群管。
- 群聊停顿 2 秒/高频 6 秒后合并，普通闲聊每群 5 分钟最多 4 次调用，间隔至少 30 秒；明确唤醒后 2 分钟最多自动跟进 2 次。
- 主人“把尾巴收一收”与“龙娘，别理他”口令进入本群持久静默，无群确认消息；只有主人实际 @ 恢复。
- `AGENTS.md`、中文教程与可重复 bootstrap，让本地 Codex Agent 按仓库链接完成正式包下载、双层摘要校验、可探测项预填与暂停控制台启动。
- EigenFlux 可选独立身份，按需安装官方 CLI、本人官网/邮箱确认与单独授权；不自动接入主 Codex Agent，不自动上传 QQ 聊天或私人人格。

## 下载与许可

正式资产命名为 `Codex-QQ-Bridge-1.0.0-Windows-x64.zip`，旁附同名 `.zip.sha256`；解压根 `Codex-QQ-Bridge` 内含逐文件 `SHA256SUMS.txt`。下载后先比对 SHA256，再解压并运行 `scripts\bootstrap.cmd` 或 `启动机器人.cmd`。后续版本沿用带版本号命名。

完整包原样附带 NapCat 4.18.41 官方压缩包与 Node.js 22.14.0 便携压缩包，并提供许可、来源与摘要。**含 NapCat 的完整包只限非商业使用，不能视为整体 MIT。** QQ、Codex 客户端和账号没有捆绑。EigenFlux 组件按需下载，不计入这两个内置运行组件。

## 实际使用边界

OneBot 自动测试使用模拟收发，不能替代本人 QQ 账号的真实群聊验收。本人仍需完成 QQ 扫码、Codex 授权及可选 EigenFlux 的邮箱/资料/边界确认。视觉、生图和音源访问取决于实际账号、CLI 工具与音源可用性。监控显示公开进度与结果，不展示内部思维原文。

升级保留 `%LOCALAPPDATA%\CodexQQBridge`（或自定义 `CODEX_QQ_HOME`）的账号、绑定、人格、记忆、表情及作品，也保留静默状态 `data/quiet-groups.json`、EigenFlux 授权状态 `data/eigenflux.json` 和独立身份 `eigenflux/.eigenflux`。这些不是清理缓存时应删除的临时文件。先暂停、等待任务结束并停止控制台，再从新目录运行新版。详见 [使用说明](usage.md)、[Agent 安装指南](agent-install.md) 与 [故障排查](troubleshooting.md)。
