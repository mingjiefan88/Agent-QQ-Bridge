# 安全与隐私

请勿公开提交QQ票据、二维码、授权代码、config.json、Codex凭据或完整聊天记录。公开Issue仅提交控制台生成的不含身份与密钥的诊断摘要，并在发送前自行检查。

程序仅监听127.0.0.1，拒绝不匹配的Host与跨站Origin，所有配置/操作接口需要本地会话令牌；OneBot回调独立校验Bearer或签名。MCP只有限定运维工具，不提供任意消息发送或命令执行。QQ消息不能赋予主人身份、修改白名单或启用本机工具。

这不能防御已控制同一Windows账号或本机的程序。QQ与Codex本地文件仍需按登录资料保护。不要把本地控制台映射到公网或关闭认证。群历史、人格、昵称和图片里的文字都作为非可信上下文处理；生图输出和附件路径另有目录/格式校验。

管理群操作前回查实际成员角色。删除/移动等不明结果不自动重放；群文件整理先预览再确认。停止进程前核对本实例记录的PID、可执行文件与创建时间，不结束不匹配的QQ实例。

第三方归属及非商业限制见THIRD_PARTY_NOTICES.md。报告漏洞请在仓库的私密安全报告入口（如已启用）联系维护者；未启用时先发不含复现凭据的简短说明，请求私密沟通方式。
