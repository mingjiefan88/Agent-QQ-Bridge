# 首次配置引导

这是待实现的产品流程，当前预览没有配置网页或安装器。

| 步骤 | 用户看到什么 | 完成条件 | 失败后的操作 |
| --- | --- | --- | --- |
| 环境 | 系统、运行时、Agent、NapCat 与媒体组件状态 | 必需组件可用，端口归属明确 | 显示具体冲突，单项安装或重试 |
| Agent | 检测到的平台、模型及能力 | 固定短提示得到真实回复 | 打开对应授权入口，保留已填内容 |
| QQ 登录 | 二维码、过期状态、机器人账号 | QQ 在线且 OneBot 就绪 | 刷新二维码、继续授权，不反复重启 |
| 主人与群 | 主人 QQ、实际已加入群及机器人角色 | 数字身份有效，选择已确认 | 重新读取，角色不足可保留普通聊天 |
| 人格与功能 | 语气预设、示例与功能开关 | 用户确认，能力和权限匹配 | 缺少能力的功能显示修复入口 |
| 检查与启动 | 配置摘要与分项检查结果 | 必需项成功后启动 | 重试当前项，真实外发独立按钮 |

常规配置自动检测并给出默认值；高级端口、超时、上下文长度等折叠展示。每步可以返回，保留输入，刷新页面后能继续。修改配置仅重验受影响步骤，取消不破坏原服务。

Agent 连接测试说明可能使用模型额度，使用固定公开文本，不带群聊。WebUI 密钥在本地遮蔽保存，不进入 URL、模型提示、普通日志或导出文件。二维码只用于当前登录，过期或登录完成后清理。

首次不继承开发者的账号、群、人格关系或历史数据。群主和管理员权限通过接口核验。默认基础聊天与上下文，主动发言、群管理和媒体功能分别启用。预设中“主人”的称呼可修改，不影响权限判断。

## 发消息测试

无外发检查自动运行。真实发送按钮在点击前展示明确的目标、内容类型、数量；点击后只执行该项，收到接口消息 ID 才标记成功。未知结果显示待确认，不自动补发。管理功能的真实变更同样需要具体目标和动作。

## 验收清单

- 空白 Windows 环境走完安装、授权、登录、群绑定和启动。
- Codex、DSH 分别验证，不能用一个平台的成功替代另一个。
- 返回、刷新、二维码过期、端口冲突、下载中断后都可恢复。
- 群/私聊不串上下文；切换引擎不重复回复。
- 真实发送、权限变更及文件操作在模拟检查中绝不外发。
- 不支持的生图和视觉功能有具体状态，不假报完成。
- 升级先备份，配置校验成功后才替换；回滚可恢复。
- 干净安装包不带私人配置、密钥和聊天历史。
