# Codex QQ Bridge

**Codex 专用的 Windows QQ 机器人插件，带统一启动器、扫码登录、人格设置与嵌入式实时监控。**

这是原开发预览的完整运行版，当前版本 `0.1.0-beta.1`。独立运行入口已实现，原来只有诊断与设计文档的空壳已替换。它使用本机 Codex CLI 和你自己的账号，不要求在机器人中填写 OpenAI API Key。

## 一键启动

1. 在本项目 [Releases](https://github.com/mingjiefan88/Agent-QQ-Bridge/releases) 下载 Windows 完整包并解压到固定目录。
2. 双击 **`启动机器人.cmd`**。完整包包含官方 NapCat 与便携 Node.js，不要求预先安装 Node。
3. 第一次自动打开配置引导：连接 Codex → 启动 NapCat 并扫码 → 完成 QQ 接口连接 → 绑定主人和群 → 填写人格 → 选择功能 → 检查并启动。

需要 **Windows x64、本机官方 QQ 客户端和可用的 Codex CLI/账号**。Codex 桌面版自带 CLI 时启动器会尝试定位；也可以在连接设置中填写 `codex.exe` 的完整路径。源码下载不包含大体积依赖，首次启动会从官方固定版本地址下载并校验 Node/NapCat；Windows 完整包可离线安装这两个组件。登录和模型调用本身仍需要联网。

日常使用默认打开状态与监控。已完成配置且登录仍有效时，一次启动会尝试恢复 NapCat 和机器人；票据过期时需要再次扫码。关闭窗口不会停止后台服务；“暂停机器人”只暂停回复并保留 QQ 登录，“停止 NapCat”关闭本启动器管理的 QQ 实例。

## 在 Codex 中作为插件使用

此仓库提供正式插件清单、一个安装运维技能与本地 MCP 工具。插件目录与独立启动包使用相同程序，不维护两份机器人。

```powershell
codex plugin marketplace add https://github.com/mingjiefan88/Agent-QQ-Bridge
codex plugin add codex-qq-bridge@codex-qq-bridge-local
```

也可以对解压后的本地目录执行 `codex plugin marketplace add <目录>`。安装后重开 Codex 会话，使用 `qq-bridge` 技能打开启动器或检查状态。MCP 提供查看状态、打开启动器、暂停与诊断四个工具；不提供任意 QQ 外发或任意终端执行工具。首次使用若尚未建立本地 Node 运行时，先双击启动器完成运行时准备。

这是 **Codex 本地插件**，没有 DSH 适配，也不承诺在网页沙盒、手机或其他 Agent 宿主运行。GitHub 分发不等于已经通过官方插件商店审核。

## 已接入的功能

| 能力 | 行为 |
| --- | --- |
| 群聊与主人私聊 | 以真实 QQ ID 绑定，默认不回应任何未授权群 |
| 持续对话 | @、唤醒词或引用唤醒后，同群同人五分钟内可连续聊天，成功回复续期 |
| 群上下文与记忆 | 最近消息、只读历史回填、明确自述、相处片段，按会话与发送者隔离 |
| 人格配置 | 通用助手、白龙娘预设与自定义人格，支持无外发预览 |
| 主动插话 | 可选低频旁听接话，至少五分钟冷却；与持续对话分别判断 |
| 戳一戳 | 戳回、多人密集戳的合并抱怨、可选随机戳与个人退出 |
| 表情包 | 视觉理解、按群收藏、选择性偷图、按上下文发送，保留 GIF 原字节 |
| 图片理解 | 真实 QQ 图片下载并作为 Codex `--image` 输入，处理后清理缓存 |
| 生图 | 主人专用、独立任务、回查真实图片文件；需要账号实际提供原生生图工具 |
| 点歌 | B站公开短音轨 → 本地转码 → QQ语音；完成和失败都清理临时音频 |
| 群管理 | 禁言、解禁、名片、撤回、群文件查看和整理；真实角色回查，整理先预览再确认 |
| 嵌入式监控 | QQ在线、任务队列、公开进度、回复与消息回执、NapCat日志、过滤与诊断摘要 |

监控不展示内部思维原文。语音输入转文字尚未提供。点歌会受音源可访问性影响；生图和视觉能力受 Codex 账号、模型与CLI工具可用性影响，失败会明确报错，不伪装成功。

## 数据和安全

- 用户数据默认在 `%LOCALAPPDATA%\CodexQQBridge`；通过 `CODEX_QQ_HOME` 可指定其他目录。升级只替换程序，不覆盖这里。
- 首次生成独立本地密钥；默认使用 `127.0.0.1:3790` 控制台、`3001` QQ接口、`6100` NapCat WebUI。
- 只监听本机，配置请求检查来源与会话令牌，QQ回调验证专用认证；群消息不能改变白名单、身份或执行本机命令。
- 本仓库和发布包没有维护者的 QQ号、群配置、登录票据、聊天记录、长期记忆、表情收藏或私人 Git 历史。
- NapCat 进程管理只处理此安装记录且仍匹配的进程；遇到占用端口会报错，不结束其他 QQ 实例。

## 验证与构建

```powershell
npm test
npm run check:release
npm run bundle
```

不需要 `npm install`。测试覆盖实际新运行入口和模拟 OneBot 收发，包含续聊、身份与权限、消息去重、认证、图片、表情、点歌清理和监控。打包只读取发布白名单，下载固定版本官方组件并校验摘要，输出到 `dist/`。

目前以本地隔离测试、实际 Codex 连接、界面交互和安装包解压校验为证据；不将模拟结果称为全新 QQ 账号端到端验收。部署到自己的 QQ 后，请先在小范围群测试。更多操作见 [使用说明](docs/usage.md)、[故障排查](docs/troubleshooting.md) 和 [安全说明](SECURITY.md)。
